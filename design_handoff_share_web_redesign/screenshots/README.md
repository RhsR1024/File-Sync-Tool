## 关于批量操作栏（`.bulkbar`）

设计如下：
- **位置**：`position: fixed; bottom: 24px; left: 50%; transform: translateX(-50%)`
- **底色**：`oklch(0.20 0.018 240)`（深石板色，不依赖深/浅模式）
- **文字**：纯白
- **结构**（从左到右）：
  1. jade 计数胶囊 + "N 项已选择"
  2. 1px 半透明白色分隔线
  3. **打包下载**（jade 填充主按钮）
  4. **删除**（红色文字按钮，仅管理员显示）
  5. 1px 分隔线
  6. **取消**（图标按钮，关闭选择）
- **阴影**：`0 10px 30px oklch(0.20 0.018 240 / 0.30)`
- **触发条件**：`selectedIds.size > 0`
- 当路径/搜索词/范围变化时自动清空选择
