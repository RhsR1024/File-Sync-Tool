Minimal Explorer 布局方向

现在只比较结构，不比较颜色细节。两版都基于你刚选的“高端网页工具”气质。

核心差异是：要不要把“状态/身份/辅助信息”独立成侧栏，让主区域更像一个专注的文件工作台。

L1. Single Canvas

所有内容都在一个主画布里，像一个非常克制的网页文件浏览器。优点是聚焦、轻盈、品牌感强。

最纯粹 文件区最大 更像高端 Web App

L2. Focus + Status Rail

主文件区保持极简，但右侧给登录态、权限提示、上传状态、最近动作留一条很窄的状态栏，层次更丰富。

更完整 状态信息更优雅 适合后续扩展
