Design Section 1: Data Model & Config

New types and config changes for local post-copy scripts

New Config Types

config.rs — New Structs
// Top-level in AppConfig.local_command_groups
struct LocalCommandGroup {
    id: String,
    name: String,
    commands: Vec<String>,       // script paths or full command lines
    on_failure: OnFailure,        // "continue" | "abort"
}

enum OnFailure { Continue, Abort }

// In ScanTask — parallel to server_bindings
struct LocalScriptBinding {
    command_group_ids: Vec<String>,  // ordered list of LocalCommandGroup IDs
}

// In ScanTask — controls local vs remote order
enum PostCopyExecutionOrder {
    LocalFirst,
    RemoteFirst,
    Parallel,
}

ScanTask Changes

ScanTask — Before vs After
Before
ScanTask {
  id, enabled, name,
  remote_path, local_path,
  rule,
  server_bindings,
}
After
ScanTask {
  id, enabled, name,
  remote_path, local_path,
  rule,
  server_bindings,
  + local_script_binding,
  + post_copy_execution_order,
}

AppConfig Changes

AppConfig — New Field
AppConfig {
  ...existing fields...
  command_groups: Vec<CommandGroup>,          // remote (unchanged)
  + local_command_groups: Vec<LocalCommandGroup>,  // local scripts (new)
}

Variable Substitution

Variable Value
${folder_name} Copied folder name (e.g., Release_01)
${local_target} Full local path (e.g., E:\Builds\Release_01)
${source_path} Remote source path
${filename} First .tar.gz filename in folder
