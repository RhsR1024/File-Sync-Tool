扫描策略

调度频率、文件稳定性检查、复制参数与过滤规则

调度频率

分钟 最小 5 分钟

文件稳定性检查

在 N 分钟内被修改过的文件，会等待 N 秒并再次校验大小未变后才复制；更旧的文件直接复制。

分钟

最小 3 分钟，推荐 3–10 分钟

秒

最小 60 秒，推荐 60–120 秒

复制参数

活跃时段

仅在此时段内扫描（例如 05:00-09:00）。留空表示全天候扫描。

05:00-09:00 20:00-23:00

文件扩展名

如 exe, tar.gz（留空表示全部）

exe tar.gz

文件名关键字

包含任意一个即可（OR 逻辑）。如 UMS, VMS

UMS VMS

命令组

可复用的 Shell 命令组，绑定到任务的服务器

解压 内置
1 条命令
cd ${remote_target} && tar -zxvf...
卸载 内置
1 条命令

手动部署

将本地文件直接上传到指定远程路径并执行命令

本地后置脚本

文件复制完成后自动执行的本地脚本（bat/PowerShell/Python）

通知运维 失败时继续
2 条命令
python scripts\notify.py...
清理临时文件 失败时中止
1 条命令
del /q "${local_target}\*.tmp"

可用变量： 文件夹名：${folder_name}（例如 Release_01） 本地目标路径：${local_target}（例如 E:\Builds\Release_01） 源路径：${source_path}（通常是共享路径，例如 \\server\share\Release_01） 第一个 .tar.gz 文件名：${filename}（例如 app-1.0.tar.gz）
