# File Share Web Homepage HTML Variants

This folder contains three homepage-only HTML review artifacts for the file share web redesign.

## Approved Direction

- Minimal Explorer foundation
- Premium web-tool feel
- Single-canvas layout
- Editorial balanced density
- Homepage only

## Variants

- `editorial-workspace.html`
  - Brand-forward and the calmest of the three
- `action-gallery.html`
  - Operation-forward with stronger action emphasis
- `content-first.html`
  - Most compressed chrome with the file list as the strongest focal point

## Open The Review Hub

Open `index.html` in a browser to compare the variants side-by-side.

## Notes

- All three variants share the same design language.
- The difference is hierarchy and emphasis, not unrelated theme changes.
- These files are review artifacts, not production Vue code.
